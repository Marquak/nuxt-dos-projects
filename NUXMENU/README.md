# NuXT Menu 1.2

A DOS menu that does a bit more than launch a list of programs. Add submenus,
browse the drive to find something to add, and pick your colours. Mouse or
keyboard, whichever you prefer.

- **Run:** copy `MENU.EXE and NUI.EXE together` to DOS; start with `MENU`.
- **Hardware:** 8088/8086 or later; text-mode display; DOS mouse driver for mouse input.
- **Full instructions:** [README.TXT](README.TXT).
- **Build:** `WATCOM=/path/to/watcom sh BUILD.SH` from this folder.

Source and current binaries are included. See [../BUILDING.md](../BUILDING.md)
and this project's test notes for validation and build dependencies.
