QEMU / FREEDOS 1.3
-----------------
The final binary passed the same 86 checks in each of:
- EGA-compatible 320x200 / 16-colour mode 0Dh on QEMU VGA.
- VGA 640x480 / 16-colour mode 12h.

Coverage includes:
- AdLib detection; the requested video mode.
- BIOS time advancing at half the new simulation tick rate.
- Player speed, release, opposite-direction cancellation and pause/resume.
- Short latched fire taps and the new projectile-slot reuse timing.
- Seven pixels of laser travel across two updates; short queued fire taps.
- Destructible shields and every one of the 50 alien collision positions.
- Formation gaps, saucer hits, player death, protection and wave progression.
- Loading all six backdrops, game over, saturation at 65535 and invasion.
- Missing-controller calibration failure, cancellation and unplug fallback.
- Four distinct marching pitches in a repeating sequence.
- Restoring the original IRQ0/IRQ1 vectors and text video on normal exit.

Additional QEMU runs covered no AdLib hardware and /S with an AdLib present.
These used actual emulated keyboard events, including 1 ms start, fire and
Escape taps, movement and key release. All passed. The gameplay fixtures
above also inject state through QEMU's debugger to reach rare cases quickly;
no test hooks or test-only code are included in INVADERS.COM.

OPL2 captures contained nonzero audio and no full-scale clipping. Final
peaks were 13,565 (EGA) and 13,493 (VGA), out of 32,767. Silent mode produced
no PCM samples. The captures' zero WAV chunk lengths were normalized in the
test copies before opening them as WAV files. These checks establish output,
not how convincing the FM march sounds on an actual AdLib and speakers.

DOSBOX 0.74-3
-------------
The final VGA binary also ran with a scripted SDL virtual controller feeding
DOSBox's real emulated gameport (2axis, timed=true), normal CPU core and a
fixed 2500-cycle setting. This exercised the compiled port-201h polling:
- Centre, full-left and full-right calibration accepted via button 1.
- Button 1 starts a game and fires.
- Full-left/full-right input moves the ship and centre stops it.
- Button 2 pauses and resumes the game.
- Escape exits cleanly; /S runs without audio.
Screenshots of the calibration stages, gameplay, movement and paused state
were reviewed. This tests a virtual analog-compatible gamepad, not a real
joystick card or a proprietary digital gamepad protocol.

VISUAL / BUILD CHECKS
--------------------
Both resolutions and all six backdrops were visually reviewed. VGA uses a
centred 640x400 image in mode 12h; the extra 80 scanlines remain black.
The final title, game-over and DOS-return displays were checked. Incremental
alien redraws and stationary-player redraw suppression are in the build.

The release source is rebuilt separately and compared with INVADERS.COM.
The ZIP and refreshed data floppy are checked against the release files.

LIMITS
------
No 86Box tests were run. QEMU and DOSBox are not cycle-accurate substitutes
for the NuXT's V20, ISA VGA bus or gameport. Real performance, joystick
calibration/noise, monitor behaviour and AdLib sound still need hardware
validation. The DOSBox cycle setting is not a measured V20 frame-rate result.
Physical EGA and DOS 2.0 compatibility are not runtime-tested; emulator DOS
runs used FreeDOS 1.3 and DOSBox. The insufficient-memory error path was not
exercised. Custom pre-existing PIT rates are not supported: the game expects
standard BIOS timing on entry and restores that timing on exit.
