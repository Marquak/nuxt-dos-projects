# Starfield 1.0

Fly through an endless field of stars. Change the speed, star count and
resolution until it looks right on your machine.

![Stars moving towards the viewer.](SCREENSHOT.PNG)

*Stars moving towards the viewer.*

- **Run:** copy `STAR.EXE` to DOS; start with `STAR`.
- **Hardware:** V20/80186 or later with VGA/SVGA. An 8087 can generate the
  perspective tables at startup.
- **Full instructions:** [README.TXT](README.TXT).
- **Build:** `WATCOM=/path/to/watcom sh BUILD.SH` from this folder.

Source and DOS builds are included. See [BUILDING.md](../BUILDING.md) for the
toolchain and [THIRD_PARTY.md](../THIRD_PARTY.md) for license details. The
original project material is [MIT licensed](../LICENSE).
