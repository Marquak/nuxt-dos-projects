# ORBIT 87 2.0

A space demo for the NuXT, with VGA graphics, some work for the 8087 and an
AdLib techno soundtrack. Both versions are here: ORBITV20 for the V20 and
ORBIT87 for a stock 8088/8086.

- **Run:** copy `ORBITV20.EXE (V20) or ORBIT87.EXE (8088/8086)` to DOS; start with `ORBITV20 /AUTO`.
- **Hardware:** VGA/SVGA; optional 8087 and AdLib. Both CPU builds share this source tree.
- **Full instructions:** [README.TXT](README.TXT).
- **Build:** `WATCOM=/path/to/watcom sh BUILD.SH` from this folder.

Source and current binaries are included. See [../BUILDING.md](../BUILDING.md)
and this project's test notes for validation and build dependencies.
