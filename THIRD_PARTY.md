# Third-party notices and provenance

## Project material

The selected source packages identify their code, pixel fonts, sprites,
procedural artwork, note sequences and OPL instrument definitions as created
for these projects. Their project-authored portions are MIT licensed. Development
used AI assistance, public hardware documentation and the research references
retained in the individual README/TESTING files. This inventory is a review of
the available source packages and development records, not a guarantee about
all possible third-party claims.

- NUXMENU: original launcher/UI/data code; DOS menu projects were design references.
- ORBIT87/ORBITV20: original scenes, score and math; IBM/Intel/NEC manuals and
  Xorg Trident register-handling code were technical references.
- STARFIELD and MATRIX: shared project drawing ideas, original effects and
  optional 8087 calculations; IBM/VBE/Trident documents were references.
- INVADERS: project-created game code, sprite/font bytes and synthesized effects;
  no Taito ROMs, extracted art or recordings. id Software's ID_SD.C was an
  AdLib programming reference, not a bundled dependency. Version 2.0 also
  consulted ID_IN.C, the FreeDOS INFOPlus archive and the documented arcade
  fleet-sound sequence. Its gameport code and wireframe scenery are original.
- NUXTLINK: DOS server, protocol, Linux client and tests; UART/FTDI
  datasheets and serial standards were references. No pyserial is needed. FileZilla queue paths were a design reference in 3.2;
  no FileZilla code was copied. The FastLynx protocol was studied through
  synthetic captures for throughput ideas; no FastLynx binary or source is included.
  The 4.0 DOS source inherits GPL-3.0-or-later terms from the earlier combined
  serial/LAN NuXT Link source, which adapted mTCP packet-driver registration.
  The Linux client remains MIT licensed. The older combined serial/LAN package
  is not included in this release; its provenance is retained here for the
  current DOS source.
- SLINKXT: continues the serial-only NuXT Link DOS and Linux code. The DOS
  source retains GPL-3.0-or-later terms; the Linux client is MIT licensed.
  Its BSUM 1.1-derived checksum is credited to Mateusz Viste under MIT terms.
  Its DOS LZ4 decoder adapts Jim Leonard's 8088 code under his Demoscene
  License, reproduced in `SLINKXT/JIM-ORIGINAL-LICENSE.TXT`. The DOS banner
  greets Jim. The heatshrink encoder is ISC licensed and the system liblz4,
  when installed, retains its BSD license. SlinkX artwork was supplied by
  the project owner.
- NUXTROIDS: original game, geometry, scenery and sound, reusing earlier NuXT
  project code. Asteroids projects, RBIL, FreeDOS INFOPlus and id Software
  drawing code were references; no Atari assets or external game code copied.
  Version 1.3 also consulted Little Game Engine and Abrash sprite/dirty-region
  discussions. The aligned-mask and difference routines are original code.
- NUXTRIS: the single-player rules adapt MIT-licensed olzhasar/sdl-tetris at
  commit 428d99d52a1de2448c7442d2655fae56aa6e9e96. The upstream MIT
  notice is preserved in `NUXTRIS/SOURCE/SP/UPSTREAM.TXT`, with details in
  `SOURCE/SP/CREDITS.TXT`. No SDL dependency. The VGA interface, effects,
  fanfare, and game selector are project code.
- NUXTRIS multiplayer builds on the single-player game and adapts Michael B. Brutman's
  mTCP packet-driver callback and registration sequence in `LAN.H`. That adapter
  is GPL-3.0-or-later, so `MP_TRIS.EXE` is distributed under
  GPL-3.0-or-later. The mTCP-derived code and its provenance are identified in
  `NUXTRIS/SOURCE/MP/CREDITS.TXT` and `NUXTRIS/SOURCE/MP/GPL3.TXT`. The original game and serial
  components remain MIT licensed. No mTCP executable or packet driver is bundled.
- SUNSET: procedural artwork generated by the included Python tool; original
  OPL2 score and instrument bank. The referenced synthwave recording is an
  inspiration, not a bundled sample, transcription or licensed recording.
  The Furnace audition contains project instrument parameters and test notes.
- NUXTDASH: original assembly dashboard; BIOS/Trident/VBE documentation,
  XTIDE structure definitions and the 8088 BIOS POST banner were references.
  No firmware source or ROM is included.
- DUNE2FIX: original compatibility patcher; metadata describes exact local game
  versions. No original or patched game executable, PAK, save or soundtrack
  is included. The patcher license grants no rights in Dune II itself.
- CW7PATCH: original 8086 timing helper and Python patcher for two verified
  Castle Wolfenstein DOS executables. Nemesis/DivByZero's VOGONS research and
  Python patch identified the DOS 3.x+ false anti-tamper checks; the research
  is credited in CW7PATCH/README.md. No original or patched Castle Wolfenstein
  executable or game data is included. The repository license grants no rights
  in the game itself.

the repository's MIT license. The Sybase Open Watcom Public License 1.0 is

## Development tools, not vendored dependencies

GNU binutils builds INVADERS, NUXTDASH and NUXMENU/MENU.EXE without a C runtime. Python and Tkinter run the
Linux client and patcher. Pillow is an optional art-generation dependency;
Unicorn, DOSBox and QEMU are optional test tools. Furnace can import the SBI
instruments and audition S3M; its executable/source is not bundled. Installing
those tools separately does not make their source part of this repository.

## Excluded material

Commercial DOS/Windows files, BIOS ROMs, complete disk images, third-party game
files, external audio/video, user CF backups, hardware diagnostic dumps, serial
saved transfer histories and user menu databases are not part of this
snapshot. The Slink-XT Linux screenshot was supplied by the owner and shows
the selected serial adapter and local test paths. Other preview PNGs are
program/procedural output.

## Screenshots

Project screenshots are captures from development runs. NuXTLink uses
sample queue data rather than a saved user transfer history. NuXT Dash
shows an emulator, so its hardware results are illustrative.

`DUNE2FIX/SCREENSHOT.PNG` shows the original Westwood Studios setup program
running with our patch applied. Dune II and its artwork/interface remain
the property of their respective rights holders. That screenshot is
included to illustrate the fix and is excluded from our MIT license.
No commercial game executable or data archive is included.

## TEXTMODE

Original assembly, no third-party code incorporated. The BIOS interface and
[Vidsync source](https://github.com/jhhoward/Vidsync/blob/main/vidsync.s) were
consulted for mode switching and hook behaviour. GNU binutils is a build tool
and is not bundled. TEXTMODE does not include Vidsync or mTCP.

## NuXTLink compression

NuXT Link 4.0 and the older 3.5.2 package include the heatshrink encoder at upstream revision
`7d419e1fa4830d0b919b9b6a91fe2fb786cf3280`, copyright 2013-2015 Scott Vokes,
under the ISC license. Source and the full notice are in
[NUXTLINK/third_party/heatshrink](NUXTLINK/third_party/heatshrink/).
The Linux native helper incorporates this encoder. The DOS assembly decoder,
CRC and UART burst routines are project code. Version 4.0 can also use the
system liblz4 under its BSD-2-Clause license; no liblz4 binary is bundled.
No FastLynx, Kermit or ZMODEM code is included.
