# Third-party notices and provenance

## Project material

The selected source packages identify their code, pixel fonts, sprites,
procedural artwork, note sequences and OPL instrument definitions as created
for these projects. Their project-authored portions are MIT licensed. Development
used AI assistance, public hardware documentation and the research references
retained in the individual README/TESTING files. This inventory is a review of
the available source packages and development records, not a guarantee about
all possible third-party claims.

- NUXMENU: original launcher/UI/data code; DOS menu projects were design references.
- ORBIT87/ORBITV20: original scenes, score and math; IBM/Intel/NEC manuals and
  Xorg Trident register-handling code were technical references.
- STARFIELD and MATRIX: shared project drawing ideas, original effects and
  optional 8087 calculations; IBM/VBE/Trident documents were references.
- INVADERS: project-created game code, sprite/font bytes and synthesized effects;
  no Taito ROMs, extracted art or recordings. id Software's ID_SD.C was an
  AdLib programming reference, not a bundled dependency.
- NUXTLINK: original DOS server, protocol, Linux client and tests; UART/FTDI
  datasheets and serial standards were references. No pyserial is needed.
- SUNSET: procedural artwork generated by the included Python tool; original
  OPL2 score and instrument bank. The referenced synthwave recording is an
  inspiration, not a bundled sample, transcription or licensed recording.
  The Furnace audition contains project instrument parameters and test notes.
- DUNE2FIX: original compatibility patcher; metadata describes exact local game
  versions. No original or patched game executable, PAK, save or soundtrack
  is included. The patcher license grants no rights in Dune II itself.

the repository's MIT license. The Sybase Open Watcom Public License 1.0 is
retained as OWLIC.TXT in those projects and licenses/OPEN-WATCOM.txt here.

## Development tools, not vendored dependencies

GNU binutils builds INVADERS without a C runtime. Python and Tkinter run the
Linux client and patcher. Pillow is an optional art-generation dependency;
Unicorn, DOSBox and QEMU are optional test tools. Furnace can import the SBI
instruments and audition S3M; its executable/source is not bundled. Installing
those tools separately does not make their source part of this repository.

## Excluded material

Commercial DOS/Windows files, BIOS ROMs, complete disk images, third-party game
files, external audio/video, user CF backups, hardware diagnostic dumps, serial
adapter identities, saved transfer histories and user menu databases are not
part of this snapshot. The supplied preview PNGs are program/procedural output.
